# Este README.md habla del flujo de procesos principales de SAP Business One, mostrando la interacción entre los diferentes módulos y cómo la información mas o menos fluye desde operaciones comerciales hasta el análisis financiero y la generación de reportes.
# Módulos
# CRM / SRM: Gestiona la relación con clientes, prospectos y proveedores. Incluye actividades comerciales, oportunidades de venta y administración de socios de negocio.
# Sales: Administra el ciclo completo de ventas, desde la cotización hasta la facturación y el cobro de clientes.
# Purchasing: Controla el proceso de compras, incluyendo solicitudes, cotizaciones, órdenes de compra y recepción de mercancías.
# Inventory: Gestiona artículos, almacenes y movimientos de inventario para garantizar la disponibilidad de productos.
# Production: Permite planificar y ejecutar procesos de manufactura a través de listas de materiales, MRP y órdenes de producción.
# Service: Administra contratos de servicio, equipos de clientes, llamadas de servicio y facturación relacionada.
# Finance: Registra y controla todas las transacciones contables, cuentas por cobrar, cuentas por pagar y gestión de efectivo.
# Reporting: Proporciona información analítica y reportes para apoyar la toma de decisiones operativas y financieras.
